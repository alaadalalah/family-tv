# تلفاز العائلة (Family TV)

مشغّل IPTV للقنوات المباشرة والأفلام والمسلسلات يعمل على **أندرويد TV والهاتف والتابلت** من كود واحد (Flutter)، مع **حماية للأطفال**.

> التطبيق مشغّل فقط. عند الإعداد الأول يضيف قائمتين عامتين مجانيتين من مشروع [iptv-org](https://github.com/iptv-org/iptv)
> (قنوات أطفال، وقنوات عربية) وهي روابط بث مجانية تتيحها القنوات للعامة. يمكن حذفهما وإضافة اشتراكك المرخّص من الإعدادات.
> - https://iptv-org.github.io/iptv/categories/kids.m3u
> - https://iptv-org.github.io/iptv/languages/ara.m3u

## الميزات

**المصادر**
- قائمة M3U / M3U8 (تُقرأ خصائص `tvg-id` و `tvg-logo` و `group-title` و `tvg-rating`).
- حساب Xtream (عنوان الخادم + اسم المستخدم + كلمة المرور): قنوات، أفلام، مسلسلات بمواسمها وحلقاتها.
- دليل البرامج EPG بصيغة XMLTV (xml أو xml.gz)، ويُجلب تلقائياً لحسابات Xtream. يظهر "الآن / التالي" على القنوات وفي المشغّل.

**الواجهة**
- عربية بالكامل من اليمين لليسار، بخط Cairo.
- تعمل بالريموت (الأسهم وزر الوسط) واللمس ولوحة المفاتيح. شريط جانبي على الشاشات الكبيرة وشريط سفلي على الهاتف.
- تصفح حسب الفئة، بحث، مفضلة لكل ملف (ضغطة مطولة على العنصر).
- المشغّل: إيقاف/تشغيل، تقديم وترجيع 10 ثوانٍ، وتبديل القنوات بالأعلى/الأسفل أو أزرار القنوات في الريموت.

**حماية الطفل**
- رمز ولي الأمر (4 إلى 6 أرقام)، يُخزَّن مشفّراً (SHA-256 مع ملح)، ويُقفل مؤقتاً بعد 5 محاولات خاطئة.
- ملفات شخصية متعددة: ملف ولي الأمر يحتاج الرمز، وملف الطفل يدخل مباشرة.
- لكل طفل:
  - **حد يومي** لوقت المشاهدة (يُحسب الوقت الفعلي للتشغيل فقط، ويُصفَّر يومياً).
  - **ساعات مسموحة** (مثلاً 8:00 إلى 20:00، وتدعم العبور بعد منتصف الليل).
  - **أنواع المحتوى المسموحة**: مباشر / أفلام / مسلسلات.
  - **الفئات المسموحة**: إما "فقط ما أختاره" (الافتراضي للأطفال) أو "الكل ما عدا المحجوب".
  - **حجب تلقائي** دائم للفئات والعناوين التي تحتوي كلمات مثل: adult, xxx, +18, للكبار, رعب... مع كلمات إضافية يضيفها ولي الأمر.
  - **التصنيف العمري** عند توفره في المصدر، مع خيار حجب الأفلام غير المصنّفة.
- تنبيه قبل انتهاء الوقت بـ 5 دقائق، ثم يتوقف التشغيل وتظهر شاشة "انتهى الوقت".
- ولي الأمر يمنح وقتاً إضافياً (15/30/60 دقيقة) بالرمز، أو يصفّر عداد اليوم.
- **قفل الجهاز على ملف طفل**: مناسب لتابلت الطفل، يفتح التطبيق دائماً على ملفه ولا يخرج منه إلا بالرمز.

## التثبيت والاستخدام على التلفاز (Android TV / Google TV)

### 1) تحميل ملف التثبيت
- رابط ثابت لأحدث نسخة: https://github.com/alaadalalah/family-tv/releases/latest/download/family-tv.apk
- **مباشرة على التلفاز**: ثبّت تطبيق **Downloader** من متجر Google Play، واكتب الرابط أعلاه في خانة العنوان، ثم اضغط Install عند انتهاء التنزيل.

### 2) نقل الملف إلى التلفاز (اختر طريقة)
- **من الهاتف**: ثبّت تطبيق **Send Files to TV** على الهاتف والتلفاز من متجر Google Play، ثم أرسل الملف من الهاتف إلى التلفاز.
- **بفلاشة USB**: انسخ الملف إلى الفلاشة وأوصلها بالتلفاز، ثم افتحها بتطبيق ملفات مثل **File Commander** أو **X-plore**.
- **من الحاسوب** (متقدم): فعّل "تصحيح أخطاء USB/الشبكة" في خيارات المطوّر، ثم `adb connect <عنوان-التلفاز>` و `adb install family-tv.apk`.

### 3) السماح بالتثبيت
الإعدادات ← التطبيقات ← الأمان والقيود ← **مصادر غير معروفة**، وفعّل التطبيق الذي ستفتح به الملف (مثل Send Files to TV أو مدير الملفات). ثم افتح الملف واضغط **تثبيت**.

### 4) أول تشغيل
1. افتح **تلفاز العائلة** من الشاشة الرئيسية للتلفاز.
2. اكتب اسم ملف ولي الأمر، ثم اختر **رمزاً سرياً** من 4 إلى 6 أرقام وأكّده. لا تُخبر الأطفال به.
3. تُضاف القنوات المجانية تلقائياً وتظهر بعد ثوانٍ.
4. لإضافة اشتراكك: ⚙️ الإعدادات ← المصادر ← إضافة مصدر ← رابط M3U أو حساب Xtream.

### 5) إعداد ملف الطفل
1. ⚙️ الإعدادات ← الملفات الشخصية ← **إضافة ملف طفل**.
2. اكتب اسمه، وحدّد **الحد اليومي** (مثلاً ساعة ونصف) و**ساعات المشاهدة** (مثلاً 8:00 إلى 20:00).
3. في **الفئات المسموحة** تكون فئات الأطفال مختارة تلقائياً؛ أضف أو أزل ما تريد.
4. اختر أنواع المحتوى المسموحة (قنوات / أفلام / مسلسلات).
5. على تابلت الطفل: ⚙️ ← **قفل هذا الجهاز على ملف طفل**، فيفتح التطبيق دائماً على ملفه.

### 6) الاستخدام بالريموت
| الزر | الوظيفة |
|---|---|
| الأسهم | التنقل بين الفئات والقنوات |
| زر الوسط (OK) | فتح / تشغيل / إيقاف مؤقت |
| أعلى / أسفل أثناء البث المباشر | القناة السابقة / التالية |
| يمين / يسار أثناء فيلم | تقديم / ترجيع 10 ثوانٍ |
| رجوع | الخروج من المشغّل |
| ضغطة مطوّلة على OK | إضافة إلى المفضلة |

- **تبديل المستخدم**: الأيقونة بجانب الإعدادات أعلى الشاشة (تحتاج الرمز عند الخروج من ملف الطفل).
- **وقت إضافي**: عند انتهاء الوقت تظهر "وقت إضافي (ولي الأمر)" وتحتاج الرمز.

## البناء من الكود

المتطلبات: Flutter 3.50 أو أحدث، و Android SDK (عبر Android Studio)، و Java 17.

```bash
flutter pub get
flutter test                 # 25 اختباراً للمنطق والواجهة
flutter build apk --release  # الملف: build/app/outputs/flutter-apk/app-release.apk
```

- **الهاتف والتابلت**: انسخ ملف APK إلى الجهاز وثبّته (اسمح بالتثبيت من مصادر غير معروفة).
- **التلفاز (Android TV / Google TV / Fire TV)**: ثبّت APK عبر تطبيق مثل "Downloader" أو بالأمر `adb install app-release.apk`. يظهر التطبيق في واجهة التلفاز بشعاره.
- **بناء تلقائي**: عند رفع المشروع إلى GitHub يبني ملف `.github/workflows/build-apk.yml` ملف APK ويرفقه بنتيجة التشغيل.

معاينة الواجهة ببيانات وهمية في المتصفح:
```bash
flutter run -d chrome -t preview/preview_main.dart   # أضف ?screen=kid أو parent أو editor أو timeup
```

## هيكل المشروع

```
lib/
  main.dart                  نقطة البدء واختيار الشاشة الأولى
  models/content.dart        المصدر، العنصر، الحلقة، تحويل التصنيف العمري
  models/profile.dart        الملف الشخصي وقيوده واستهلاك اليوم
  services/m3u_parser.dart   قراءة قوائم M3U
  services/xtream_client.dart واجهة Xtream
  services/epg.dart          دليل البرامج XMLTV
  services/parental.dart     قواعد الحماية (الفئات، العمر، الوقت)
  services/app_state.dart    الحالة والتخزين والرمز السري
  screens/                   الشاشات
  widgets/                   بطاقة تدعم الريموت، لوحة الرمز
test/                        الاختبارات
```

## حدود معروفة في النسخة الأولى

- يُحسب الوقت داخل التطبيق فقط. لمنع الطفل من الخروج إلى تطبيقات أخرى استخدم "تثبيت الشاشة" في أندرويد أو Google Family Link.
- أغلب مصادر IPTV لا تذكر التصنيف العمري، لذا الحماية الأساسية هي **الفئات المسموحة**.
- المحتوى يُعاد تحميله عند كل فتح للتطبيق (لا يوجد تخزين مؤقت للقوائم الكبيرة بعد).
- المشغّل يعتمد على ExoPlayer (HLS و MPEG-TS و MP4). بعض صيغ MKV أو الترميزات النادرة قد لا تعمل.
- البيانات (ومنها كلمات مرور Xtream) مخزّنة محلياً على الجهاز في إعدادات التطبيق.
